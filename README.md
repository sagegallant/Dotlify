# Dotlify 📧

> A fast, privacy-focused email alias generator that creates thousands of aliases from a single email address — entirely in your browser.

**Dotlify** is a responsive, client-side web application for generating and managing email aliases using multiple aliasing strategies. It supports dot variations, plus addressing, alternative domains, and combined methods, while providing filtering, randomization, clipboard copying, and multiple export formats.

The application requires no backend, database, account, or server-side processing for generating aliases. Everything happens directly in the user's browser.

## ✨ Features

### 📧 Multiple Alias Generation Methods

Dotlify supports several approaches to generating email aliases:

#### Dot Method

Generates variations by inserting dots into the local part of an email address.

Example:

```text
username@gmail.com
u.sername@gmail.com
us.ername@gmail.com
use.rname@gmail.com
u.s.ername@gmail.com
